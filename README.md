# C++ Exercises

### ex00
This exercise demonstrates the basics of **dynamic** and **static** memory management in C++.

### ex01
The goal of this exercise is to practice **dynamic memory allocation** using arrays.

### ex02
This exercise helps you practice working with **pointers** and **references** in C++.

### ex03
This program demonstrates how to use **composition** and **pointers** in C++ with two classes.

### ex04
This exercise shows how C++ can **access**, **read**, and **create** files.

### ex05
This exercise teaches how to use **function pointers** to dynamically call member functions based on user input.

### ex06
This exercise helps you understand how to use **function pointers** in conjunction with control flows like `switch`, enabling **flexible behavior** based on user input.

---

### How to Run the Exercises

1. Clone the repository.
2. Compile each exercise using "make" inside each directory.
